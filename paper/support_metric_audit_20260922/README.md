## 1. 消融实际检验什么

| 变体 | 代码干预 | 保留内容 |
|---|---|---|
| w/o Age | 年龄通道改填观测mask，不改变通道数 | 角色输入、角色相关图修正、角色平衡损失 |
| Mask-only | 角色与年龄通道均改填mask；图修正角色尺度改为各角色尺度平均 | 图修正网络、真实角色监督与角色平衡损失 |
| w/o Role Balance | 角色平衡混合系数0.1改为0 | 全部角色/年龄输入、推理网络、Focal基础项及辅助项 |
| Local Temporal Context | 跳过空间分区索引扩展/重排，逐节点调用forward_local，禁止跨节点信息交互 | 输入嵌入、注意力投影、潜在router、FFN、FiLM、参数总量 |
| w/o Learned Imputation | 共享GRIN替换为ObservedOnly；不可见位置填标准化0 | 真正可见值及mask/其他状态通道；标准化0对应训练均值，不是物理速度0 |
| Plain MAE | 仅以普通MAE替换误差调制基础损失 | 角色平衡及辅助项，非全部训练目标只剩MAE |

代码：`experiments/alfnet_ablation_adapter.py`、`model/ALFNet/ALFNet.py`、`model/ALFTemporal/patchstg.py`、`experiments/focal_loss.py`。

Mask-only并非纯粹“去角色”实验：Full的修正尺度AAS/NAS/VS/FS为0/1/1/0.25；Mask-only采用平均0.5625。因此它同时改变状态输入与输出修正的条件化，不能单独归因角色是否有用。w/o Age增加LifeAvg MAE/RMSE/MAPE2.07%/0.43%/3.62%，支持年龄在当前角色设计下的条件贡献；不构成角色、年龄联合设计必然优于mask的证明。Mask-only和去角色平衡的平均指标更好应保留，其Cold或Join代价同时报告。

Static Propagation不是全面更优：平均MAE/RMSE分别增加0.98%/1.00%，MAPE降低1.62%。MAE与RMSE为速度单位，MAPE为百分比，没有预定权重不能把三项数值直接相加定义“整体更好”。

Local Temporal Context不是单独删TSA或只改变分区数量。它重新组织同一组模块，使每个节点只处理自己的历史嵌入。当前tem_patchsize=12、tem_patchnum=1，历史已嵌入为单个时间token；不能将这个消融描述成只删某个时间注意力层。该变体支持跨节点上下文的整体价值，不精确区分分区重排与两阶段交互的单独贡献。

## 2. Focal基础项

令原速度尺度上的绝对误差为 $e$，训练标准差为 $s$。普通MAE单元素损失为 $e/s$；当前实现为

$$\ell_{\rm focal}=\frac{e}{s}[2\sigma(0.2e)-1]=\frac{e}{s}\tanh(0.1e).$$

小误差附近近似 $0.1e^2/s$，大误差时趋近 $e/s$。这是回归误差调制MAE，并非分类Focal，也不是MAPE目标。权重参与梯度，没有detach。作用是相对降低小误差项权重，不保证MAE、RMSE、MAPE同步改善。Full进一步混合0.9基础均值与0.1角色平衡项，并含辅助损失。PlainMAE只替换上式。

## 4. 基线与论文图示参考

不建议移除UIGNN。GinAR确属变量缺失预测模型，但其当前完整验证指标较弱，不能仅因更容易获胜而替代已经选定的最强类别代表。HA是简单统计/惯性参照，FC-LSTM是一般时序模型；本仓库HA具体实现为历史惯性复制。STGODE是一般图时空预测模型。它们可以作为补充参照，不能因为被适配到缺失输入就改称专门的“不完整观测预测”代表。

已核验[GinAR原文§4.5–4.6](https://arxiv.org/html/2405.11333v1)：参数分析与空间预测可视化承担不同任务，不必所有实验都画同一种误差曲线。[STGODE原文§5.5](https://arxiv.org/pdf/2106.12931)展示两个节点的预测序列；本地MoGERNN§5.6使用RMSE与推理时间回答专家数问题。这些例子支持按科学问题选择图形，不构成按照模型排名选择指标的依据。

## 6. 怎样回应审稿质疑

当前已较明确支持：跨节点上下文、学习式重建和完整时间调制分支，以及统一协议中的综合性能。角色状态、角色平衡、动态路由和Focal应描述为有条件的设计选择，不能宣称都提供无条件平均增益。

如果后续一定要独立论证角色输入，则需另立验证集计划，把角色输入与角色修正尺度拆开，固定年龄、损失及输出修正作单因素控制，并做配对种子验证。若要解决真实的短历史泛化弱点，应先在验证集按可用观测数、邻居支持量、速度区间和残差方向诊断，再决定是否重开模型优化。当前模型已冻结，本轮不自动启动这些训练；更换图形不会改变能力。
