# PPT 重建图元指南（v4）

本指南以 `alfnet_architecture_v4_vector.svg` 为几何依据：其中全部为矩形、圆、折线、多边形、路径和文本（无嵌入位图）。可插入 PowerPoint 后"转换为形状"再拆分；**本轮未在本机 PowerPoint 实测拆分效果**。生图版 PNG 仅作风格参考，不能拆分为原生对象。

设计单位 2400×1350；按 33.867 cm（16:9 幻灯片宽）放置时 1 单位 ≈ 0.141 mm。

| 模块 | 参考图出处 | 基础形状与做法 |
|---|---|---|
| 区域容器（补全/时间/图/生命周期） | 图5 浅色圆角容器 | 圆角矩形，浅填充 + 2 pt 同色系描边；子模块用白底圆角矩形 + 1.4 pt 描边 |
| 可见历史曲线 | 图1 观测曲线 | 折线 + 小实心圆；缺失位置画空心灰圆在基线上 |
| Lifecycle 角色条 | 图7 Mask 方块 / 图6 token 网格 | 每行 12 个小矩形，按 AAS/NAS/VS/FS 四色填色；下方 4 个色块图例 |
| aₜ / Mₜ | 图7 Mask | aₜ：12 个底对齐竖条；Mₜ：2×12 小方格，紫/白 |
| 静态图与 A | 图3 节点图 | 圆 + 直线；A 为 6×6 方格，按所画边对称填色 |

| ToD / DoW | 图4 时钟/日历图标 | 时钟：圆 + 两短线；日历：圆角矩形 + 红色顶条 + 3×2 小格 |

| Cross-partition | 图6(d) 高亮格 + 图3 连接弧 | 同一行（同槽位）加 3 pt 深色描边框，行上方 4 条二次曲线弧 |
| Within-partition | 图4 token 组 | 左 5 格竖条（C 槽）→ 中间 4 个深绿圆角小方块（4 latent tokens）→ 右 5 格竖条；细灰连线；下方两支箭头 "Gather"、"Broadcast" |

| 线型与图例 | 图4/图3 底部图例 | 黑实线=数据/参数；紫虚线=生命周期条件；灰框字母=静态图端口；蓝虚线无箭头=cell 定义引线 |
