# 4 实验

本节在 METR-LA 和 PEMS-BAY 上评估 ALFNet 在动态观测支持下的归纳预测能力，并通过观测条件分解与替代式消融，分析整体收益的分布及其与模型设计的关系。

## 4.1 实验设置

**数据集与预测任务。** METR-LA 和 PEMS-BAY 分别包含 207 和 325 个交通传感器，具有 34,272 和 52,116 个时间点，采样间隔均为 5 分钟。模型根据过去 12 步历史预测未来 12 步交通速度，即使用过去一小时的信息预测未来一小时。时间序列按先后顺序划分为 60% 训练集、20% 验证集和 20% 测试集。在拓扑已知的归纳设置下，训练仅使用训练节点的动态信号，评价时纳入未参与训练的保留节点；标准化统计量仅由训练时间段内的训练节点计算。本稿报告验证集结果。

**观测支持协议。** 在共同的节点划分和预测窗口下，设置 Unseen、Steady、Join 和 Fault 四类等配额观测条件，分别对应零历史观测、持续观测、逐步加入观测和观测中断。Join 根据加入后的历史长度细分为 Cold、Warm 和 Ready，分别对应 1 步、2–11 步和 12 步；Fault 则按中断后的进展长度划分为 Onset、Decay 和 Outage，分别对应相同的时间区间。随着中断持续，输入窗口中保留的历史观测逐渐减少。自然缺失与上述协议共同决定最终观测掩码，因此阶段长度与实际有效观测数并不总是一致。所有方法在相同的观测条件和预测目标上进行评价。

**比较方法。** 选取 HA、FCLSTM、STGCN、STGODE、STID、SLPF、STBP 和 MoGERNN 作为比较方法，覆盖统计预测、时间序列建模、图时空预测及归纳预测。各方法遵循共同的数据暴露范围、输入与预测长度及指标计算方式，并保留各自架构所需的输入接口和训练设置。[TODO：补齐数据集与各基线的原论文引用。]

**评价指标。** 使用平均绝对误差（MAE）、均方根误差（RMSE）和平均绝对百分比误差（MAPE），均在还原后的速度尺度上计算，MAPE 以百分比表示。各条件内部按日历分层与事件进展长度进行平衡汇总，再对四个主条件的指标取等权平均，得到综合指标 LifeAvg。因此，LifeAvg 衡量不同观测条件下的平衡表现，其中 RMSE 为条件级 RMSE 的平均值。

**实现细节。** ALFNet 使用 AdamW 优化器，批量大小为 64，权重衰减为 \(10^{-4}\)，最多训练 100 轮并采用提前停止。共享历史重建与 ALFGraph、ALFTemporal、FiLM 调制头与图输出修正模块的学习率分别为 \(5\times10^{-4}\)、\(10^{-4}\) 和 \(5\times10^{-5}\)，模型依据验证集 LifeAvg MAE 选择。METR-LA 与 PEMS-BAY 的空间分块容量分别为 8 和 11。消融模型沿用完整模型的数据划分、训练目标和优化设置，参数分组细节见附录 A.6。

## 4.3 不同观测条件下的预测性能

图 2 将 METR-LA 的总体结果分解为四个主条件和六个事件阶段，统一以与 ALFNet 架构来源相关的外部基线 MoGERNN 为参照，报告 MAE、RMSE 与 MAPE 的相对降低比例。固定比较对象后，可以直接观察 ALFNet 相对同一模型的收益如何随观测支持条件变化。

![METR-LA 主条件与六阶段的相对误差分解](/media/xd/38162e9d-06bd-4953-8790-0bc340486a80/ZMY/MoGERNN/paper/figures/METRLA_condition_gains.png)

**图 2　METR-LA 不同观测支持条件下相对于 MoGERNN 的预测收益。** （a）四个主条件；（b）六个事件阶段。所有单元格均按 \((E_{\mathrm{MoGERNN}}-E_{\mathrm{ALFNet}})/E_{\mathrm{MoGERNN}}\times100\%\) 计算，正值表示优于 MoGERNN，负值表示劣于 MoGERNN。逐条件最优基线的绝对值与比较结果另见附录表 A1。

**观测中断下的收益。** Fault 条件下，ALFNet 相较 MoGERNN 的 MAE、RMSE 和 MAPE 分别降低 10.03%、7.95% 和 2.92%。阶段分解显示，Onset 的 MAE 降低 13.26%，Decay 和 Outage 分别降低 9.75% 和 10.01%，三者的 RMSE 与 MAPE 也均有所改善。收益从中断初期延续至整个窗口失去本地历史，说明 ALFNet 相对 MoGERNN 的改善覆盖不同程度的历史支持退化，与根据观测条件组织空间证据及预测上下文的设计目标相符。

**加入观测下的差异。** Cold、Warm 和 Ready 相较 MoGERNN 的 MAE 分别降低 3.14%、12.47% 和 13.39%。Cold 的三项指标虽均有改善，但收益小于后两个阶段，表明极短历史下的增益相对有限。Ready 的 RMSE 和 MAPE 分别降低 11.48% 和 9.36%，显示较充分的历史支持有利于发挥该框架的相对优势。这些阶段对应不同评价样本，配对条件下的支持变化将在 4.5 节进一步考察。

**零历史与稳定观测。** Steady 下三个指标均有所改善，Unseen 下 MAE 与 RMSE 仅降低 2.00% 和 1.87%，MAPE 则上升 2.97%。因此，条件化预测的收益并非只存在于事件过渡期，但零历史归纳预测仍具有明显难度。图 2 展示的是相对于 MoGERNN 的收益分布；在附录的逐条件最优基线比较中，Cold 和 Warm 的 MAE 仍落后于 FCLSTM，Outage 的 MAE 也未超过 STBP。固定参照下的正收益与这些局部差距可以同时存在。

## 4.4 消融研究

为考察观测状态、条件化传播和空间上下文各自的作用，在 METR-LA 上构造三种替代模型，保持预测任务和训练流程一致。

**Mask-only** 保留完整观测掩码，用掩码特征替代显式角色与观测年龄输入，并将输出修正中的角色相关尺度固定为常数。训练时的角色平衡监督保持不变，因此该比较考察显式状态在预测前向过程中的作用。**Static Propagation** 保留 ALFGraph 的传播算子、循环结构和解码器，将输入相关的传播混合替换为可学习的全局固定混合。**Local Temporal Context** 保留 ALFTemporal 的时间表示结构与调制接口，使其逐节点处理时间片，取消该分支的跨节点动态上下文交互；历史重建和图推理分支仍保留空间信息。Mask-only 与 Local Temporal Context 的参数量与完整模型相同，Static Propagation 的参数量仅减少约 0.064%。

**表 2　METR-LA 上的替代式消融结果。** 三种变体分别检验显式观测状态、观测条件化传播和跨节点时间上下文的作用，均保留相应分支的基本预测功能。指标为 LifeAvg，粗体表示最优结果。

| 模型 | LifeAvg MAE↓ | RMSE↓ | MAPE(%)↓ | 参数量 |
|---|---:|---:|---:|---:|
| Full ALFNet | **4.638** | **6.807** | 14.626 | 1,037,529 |
| Mask-only | 4.818 | 6.942 | **14.382** | 1,037,529 |
| Static Propagation | 4.914 | 7.033 | 14.610 | 1,036,869 |
| Local Temporal Context | 5.035 | 7.072 | 14.665 | 1,037,529 |

**显式观测状态提供的归纳偏置。** 仅使用完整掩码时，四个主条件的 MAE 均上升，LifeAvg MAE 和 RMSE 分别上升 3.89% 和 1.99%。其中，Unseen 与 Fault 的 MAE 分别上升 5.45% 和 4.08%，表明显式状态条件化的收益覆盖零历史和观测中断情形。在相同训练监督下，这一差异支持将角色与观测年龄显式提供给预测过程：它们为模型解释当前历史支持提供了结构化条件，从而有助于组织重建和后续时空计算。这种作用体现为一种归纳偏置，而非要求状态变量含有完整掩码之外的新信息。Mask-only 的 MAPE 更低，说明显式状态的优势主要体现在本实验的 MAE 与 RMSE 上。

**条件化传播对有限历史的作用。** 使用全局固定混合后，LifeAvg MAE 和 RMSE 分别上升 5.96% 和 3.32%，其中 Unseen 的 MAE 上升 12.02%，Join 上升 4.11%，高于 Fault 的 1.21%。传播算子保持不变时，较大的差距集中在缺乏本地历史的 Unseen 条件，说明固定的算子组合难以充分适配不同节点可用的历史证据。ALFGraph 的条件化混合允许传播策略随输入条件调整，这一设计有助于在本地时间信息不足时利用空间证据。该现象也表明，图推理的作用应从不同历史支持条件来理解，而不局限于故障场景。

**跨节点上下文对时间表示的作用。** 将时间分支限制为局部上下文带来三项消融中最大的综合 MAE 增幅，LifeAvg MAE 和 RMSE 分别上升 8.55% 和 3.90%。Unseen 与 Join 的 MAE 分别上升 12.49% 和 7.53%，四个主条件的 MAE 均有所恶化。该变体仍保留图推理和空间重建，因而这一差异说明，预测上下文中的跨节点交互能够在已有空间传播之外补充局部时间表示。参数量不变时仍出现上述退化，支持 ALFTemporal 将空间上下文用于时间表示条件化的设计。

三项替代均提高了综合 MAE 与 RMSE，但 MAPE 的排序有所不同，其中 Mask-only 与 Static Propagation 略优于完整模型。消融结果因此呈现出明确的指标侧重：显式条件信息、可调整传播和跨节点上下文共同支持较低的绝对预测误差，而其对相对误差的影响并不完全一致。

## 4.5 观测支持机制分析

为考察归纳预测对观测支持的响应，正文使用验证保留节点上的 64 个配对窗口，覆盖 25 个验证保留节点中的 23 个。这里的保留节点属于固定划分中的验证节点集，其动态信号未参与训练，但图拓扑已知，验证时可以使用符合观测协议的历史；训练已知节点则属于训练信号可见的节点集。后者的 64 个窗口单独在附录展示，不与正文结果混合。

样本在查看预测误差前选定，要求历史及未来各 12 步自然观测完整。每组固定节点、预测时刻、真实未来、图结构和其他节点输入，仅改变目标节点的历史支持，重新生成合法的掩码、角色、观测年龄，并由模型重新计算历史重建。设置完整历史、Join-3、Join-6、Fault-3、Fault-6 和 Outage 六种轨迹；Join 的数字表示加入后保留的近期观测数，Fault 的数字表示中断步数。这些名称表示施加在同一保留节点上的支持轨迹，不改变节点的训练划分身份。误差对窗口与预测步等权计算，RMSE 由合并平方误差开方得到。

![METR-LA 保留节点的配对观测轨迹干预](/media/xd/38162e9d-06bd-4953-8790-0bc340486a80/ZMY/MoGERNN/paper/figures/METRLA_trajectory_intervention.png)

**图 3　验证保留节点上的观测轨迹干预。** 所有面板使用相同的 64 个窗口。（a）目标节点的历史支持，深色表示可观测位置；（b）ALFNet 与外部强基线 MoGERNN 的 MAE；（c）完整 ALFNet 相对于内部控制 Mask-only 的 MAE 降低比例，即 \((E_{\mathrm{Mask\text{-}only}}-E_{\mathrm{ALFNet}})/E_{\mathrm{Mask\text{-}only}}\times100\%\)，正值表示完整模型更优。两类比较分别考察外部预测收益与显式状态的作用。完整三指标及训练已知节点结果见附录表 A2 和图 A1。

**保留节点上的预测响应。** ALFNet 在六种轨迹下的 MAE 均低于 MoGERNN，但优势随支持条件改变。完整历史下，二者 MAE 分别为 3.713 和 4.518，ALFNet 降低 17.81%；完全中断时分别为 6.266 和 6.331，优势收窄至 1.03%。此时 RMSE 也十分接近，ALFNet 的 MAPE 则高于 MoGERNN。可见，失去本地历史对保留节点预测构成更强约束；在其他轨迹中观察到的收益不能直接外推为完全中断时的同等优势。

**内部状态控制。** 图 3（c）将显式状态的作用与外部模型比较分开。Fault-6 下，完整 ALFNet 的 MAE 为 4.428，Mask-only 为 4.845；Outage 下分别为 6.266 和 6.840，对应降低 8.61% 和 8.39%。Fault-3、Fault-6 与 Outage 的 RMSE 和 MAPE 也优于 Mask-only，支持显式观测状态在中断条件下的作用。完整历史与 Join-6 下则是 Mask-only 略优，说明该归纳偏置的收益具有条件性。同有六步观测时，Join-6 与 Fault-6 的 ALFNet MAE 分别为 4.029 和 4.428；由于时间位置与事件状态同时变化，下一节保持角色状态不变，进一步区分观测数量和布局。

## 4.6 观测支持数量与时间布局

数量与布局分析沿用完整的 128 个配对窗口，其中训练已知节点与验证保留节点各 64 个，对两类节点等权汇总。定义 \(q\) 为 12 步历史内实际可用观测数，取 \(q\in\{0,3,6,9,12\}\)。同一 \(q\) 下分别保留近期观测（Recent）、早期观测（Early）、分散观测（Dispersed），或删除中间连续区间而保留两端观测（Middle gap）。布局按固定的离散位置规则构造，精确公式和二进制掩码见附录 A.3。该实验模拟持续部署传感器的通信层观测删减，保持成熟活跃角色及观测年龄不变，使数量与布局的比较不混入传感器加入或失效标签变化。所有掩码均通过删减真实观测构造；\(q=0\) 与 \(q=12\) 各为一个公共端点。

![METR-LA 可用观测数与时间布局分析](/media/xd/38162e9d-06bd-4953-8790-0bc340486a80/ZMY/MoGERNN/paper/figures/METRLA_q_temporal_layout.png)

**图 4　观测支持数量与时间布局对预测的影响。** （a）ALFNet MAE；（b）MoGERNN MAE，两图共用误差色标；（c）ALFNet 相对于 MoGERNN 的 MAE 降低比例（%）。每个单元格对应同一组 128 个配对窗口（已知节点、保留节点各 64 个），表示两类节点的均衡总体响应。\(q=0\) 和 \(q=12\) 在各行重复显示共同端点，不代表额外独立样本。RMSE、MAPE 及 Mask-only 结果见附录表 A3。

**数量相同并不意味着支持等价。** 随着 \(q\) 增加，ALFNet 在四种布局下的 MAE 均降低，但相同数量下仍存在明显布局差异。在 \(q=6\) 时，仅保留早期历史的 MAE 为 4.447，保留近期历史为 3.743，保留中间缺口两侧历史为 3.652。这说明历史观测的时间位置会影响预测质量，单一可用比例不能完整描述预测条件。Middle gap 尽管包含连续缺失，仍能取得较低误差，也提示连续缺失的长度需要结合保留观测的位置理解。

**相对收益依赖可用证据的分布。** ALFNet 在全部已构造组合下的 MAE 与 RMSE 均低于 MoGERNN，MAE 降低幅度为 0.17%–18.53%。优势较弱的情况是仅保留较早历史：\(q=3\) 时 MAE 仅降低 0.17%，而同样三步观测采用 Recent 或 Middle gap 布局时分别降低 10.35% 和 12.81%。当 \(q=9\) 且观测分散时，MAE 降低 18.53%。这些结果表明，ALFNet 的相对收益与历史证据的数量及分布共同相关，不能简单概括为观测越少优势越大。MAPE 在无历史以及少量早期历史的部分组合下仍高于 MoGERNN，说明这些信息受限条件下的相对误差仍是当前边界。
