\section{引言}\label{sec:intro}
交通预测为路网运行管理、出行规划与拥堵预警提供前瞻性信息，而预测所依赖的传感网络在不断变化：路网扩建会带来新装的检测器，设备故障与通信异常会使原有检测器中断，受预算限制，许多需要预测的位置也从未安装传感器~\citep{yin2025xxltraffic,zhou2025mogernn}。这些变化直接体现在模型读到的历史中。一个刚接入的检测器，在历史窗口里只有最近几步读数；一个刚失效的检测器保留了较早的读数，却失去了最近的读数；还有一些位置在窗口内始终没有读数。同一位置在不同窗口之间，甚至在同一个窗口之内，可用的信息都可能不同。本文将历史窗口内实际可用观测的位置、数量及其时间分布统称为观测支持（OS）。

已有研究从多个角度处理过这类情形。归纳预测把模型推广到训练期没有动态信号的位置，能够预测无传感器位置的未来状态，或在只有少数节点提供训练数据时泛化到其余节点~\citep{zhou2025mogernn,roth2022forecasting,mei2023uncertainty,gupta2023frigate,lei2025stfit}；不完整观测下的预测处理输入中的缺失，其中一些方法让计算依赖掩码、距上次观测的时间间隔等缺失信息~\citep{yu2024ginar,yu2025merlin,marisca2024graph,che2018recurrent}；面对传感网络的演化，持续学习、少步适应与分布外泛化方法分别通过增量训练、少量目标观测或不更新参数的方式处理新增节点~\citep{chen2021trafficstream,wang2023pattern,liu2026general,wang2026cold,zhao2026structure,wang2024stone,ma2025robust}。因此，未观测位置、读数缺失与传感器配置变化本身都不是新问题。较少被显式刻画的，是这些变化作为事件的过程：已有方法多以掩码或节点所属的配置描述观测是否可用，部分方法还记录距上次观测的时间；而一个位置是刚接入还是刚失效、事件已经持续了多久，较少作为显式变量参与空间信息交换的组织，评价时也较少按事件持续的步数区分预测表现。

本文因此研究动态 OS 下的归纳时空预测：路网拓扑已知，部分节点的动态信号不参与训练，推理时模型参数固定，而各位置的 OS 可以在历史窗口内变化。按目标位置在窗口内的观测轨迹，我们考察四类场景：训练中没有动态信号的保留节点全程没有读数（零历史，Unseen），或在窗口内接入并开始提供读数（新增接入，Join）；参与训练的已知节点全程可读（稳定观测，Steady），或在窗口内中断（故障中断，Fault）。本文假设各位置的接入与失效状态已知，实际中可由接入记录与故障检测获得；模型只依据历史窗口内的 OS 进行预测，不预测未来观测状态的变化。在此设置下，本文的核心问题是：\textbf{当目标位置的 OS 在历史窗口内变化、而模型参数固定时，预测计算应如何依据 OS 调整对本地历史与空间上下文的利用。}

我们的核心认识是，\textbf{OS 不仅描述哪些输入有效，也应作为组织预测计算的条件}。为此，我们用三类逐步变量描述 OS。观测掩码标明读数是否可用。观测角色沿用已有研究对传感器的划分~\citep{zhou2025mogernn}：持续可用传感器（AAS）在训练与推理期间稳定提供读数，新增传感器（NAS）在训练期没有记录、接入后才开始积累读数，失效传感器（FS）原本正常工作、后来中断读数，虚拟传感器（VS）没有可读观测、只需要预测；窗口内全无读数时，掩码不能区分从未接入与已经失效，观测角色可以。状态进度（state progress）描述接入或失效已经持续的比例，同时刻画接入后证据的积累与失效后证据的流失，而距上次观测的时间间隔只刻画后者。这些变量需要在计算的几个环节发挥作用：补全缺失读数之后，后续计算仍应知道哪些值来自观测；本地读数很少或已经中断时，预测需要借助关联位置的历史；空间信息的交换方式也应能随观测状态改变。

据此，我们提出 ALFNet（Adaptive Lifecycle Forecasting Network），其中"自适应"指计算随输入的 OS 而变化，推理时模型参数保持固定。观测支持感知历史补全（SAHC）依据可见读数、OS 与路网关联，为全部节点补全一份共享历史，OS 随这份历史一起交给后续两个分支。空间上下文时间条件分支（ALFTemporal）把节点组织为空间分区，从跨节点的共享历史与 OS 中生成逐节点的条件特征，经特征级线性调制（FiLM）作用于图预测分支的编码状态，为本地历史不足的节点提供来自关联位置的依据。观测条件化图预测（ALFGraph）在编码时由每一步的 OS 决定多种图传播算子的组合，使空间信息的交换随观测状态改变，接受调制后再解码生成预测，解码沿用历史窗口末步的 OS。三个模块分别借鉴了图循环插补~\citep{cini2022filling}、空间分区交互~\citep{fang2025efficient}、两阶段注意力~\citep{zhang2023crossformer}、特征级线性调制~\citep{perez2018film}、图专家混合~\citep{zhou2025mogernn,wang2023graph} 与扩散卷积循环网络~\citep{li2018diffusion} 的思想。与最接近的 MoGERNN 相比，ALFNet 同样使用图专家混合，区别在于路由的依据与作用位置：MoGERNN 依据节点输入特征稀疏地选择专家，并在进入编码—解码器之前为未观测节点构造表示；ALFNet 的路由只由 OS 决定、不读取信号值，并作用于编码器每一步的门控图传播。

我们在 METR-LA、PEMS-BAY、PEMS04 与 PEMS08 四个数据集上，与归纳预测、缺失感知预测与时空表示三类共八个方法统一比较。ALFNet 跨场景平均误差（LifeAvg）的三项误差指标均优于所列方法，平均绝对误差（MAE）降低7.86\%–15.63\%；在本地证据逐步积累或中断的 Join 与 Fault 场景下，四个数据集的三项指标均为所列方法中最优；在全程没有本地历史的 Unseen 场景下，优势依赖数据集，两个流量数据集的 MAE 与 RMSE 尚未取得最优。组件消融中，去除跨节点上下文或整个时间条件分支时误差上升最多；以全局权重替代 OS 路由、以掩码替代状态进度，也使多数数据集与指标上的误差上升。固定预测目标的观测干预显示，模型的预测随本地历史的加入与中断而变化，相同数量的可见读数集中在近期时误差更低。

本文的贡献概括为三点：（1）在已有传感器类型划分的基础上，提出动态 OS 下归纳预测的评价协议：按目标位置的观测角色轨迹划分场景，并按接入或失效后的持续步数划分阶段，用以检验预测能否随本地证据的积累与流失而调整；（2）提出 ALFNet，使 OS 同时进入共享补全、跨节点时间条件与图传播路由，三者共用同一份补全历史，并由时间条件分支调制图预测的编码状态；（3）四个数据集上的统一比较表明，ALFNet 的跨场景平均误差优于所列八个方法，优势在 Join 与 Fault 场景上最稳定；组件消融与观测干预进一步表明，跨节点上下文的贡献最大，预测会随 OS 的变化作出相应调整。
