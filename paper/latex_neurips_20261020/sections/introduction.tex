\section{引言}\label{sec:intro}
交通预测根据路网上传感器的历史读数预测未来的速度或流量，是信号控制、路径诱导和拥堵预警的基础。多数预测模型默认每个位置在历史窗口内都有完整的读数，但实际的传感网络做不到这一点：受预算限制，许多需要预测的位置从未安装传感器；路网扩建会接入新的传感器，它们起初只有很短的历史；设备故障或通信异常又会让原本正常的传感器中断读数~\citep{yin2025xxltraffic,zhou2025mogernn}。如图\ref{fig:intro-support}所示，在同一时刻的路网上，有的位置历史完整，有的位置只有最近几步读数，有的位置刚丢掉最近的读数，还有的位置完全没有读数。本文关心的就是这种情形下的预测：路网拓扑已知，部分位置的读数不参与训练，历史窗口内可以发生传感器的接入或失效，模型在推理时不更新参数，需要用同一组参数预测所有位置未来的交通状态。我们称之为动态观测支持下的归纳时空预测，其中观测支持（OS）指历史窗口内实际可用读数的位置、数量和时间分布。

已有研究分别处理过其中的一部分。归纳预测方法把模型推广到没有训练数据的位置，可以预测无传感器位置的未来状态~\citep{zhou2025mogernn,roth2022forecasting,mei2023uncertainty,gupta2023frigate,lei2025stfit}；面向缺失数据的预测方法处理输入中缺失的读数，其中一些还把掩码或距上次观测的时间间隔作为输入~\citep{yu2024ginar,yu2025merlin,marisca2024graph,che2018recurrent}；面向传感网络变化的方法通过持续学习、少量样本适应或分布外泛化来应对新增的节点~\citep{chen2021trafficstream,wang2023pattern,liu2026general,wang2026cold,zhao2026structure,wang2024stone,ma2025robust}。这些方法大多用掩码或节点所属的类别来描述读数是否可用。然而，掩码只说明某一步有没有读数：当一个位置在窗口内完全没有读数时，掩码分不清它是从未接入还是刚刚失效；当它只有几步读数时，掩码也不说明接入或失效已经持续了多久。这两点恰恰关系到预测应当依靠什么：刚接入的位置只有很少的本地读数，需要更多地借助关联位置；刚失效的位置还保留着较早的读数，这些读数的参考价值会随失效时间变长而下降。MoGERNN~\citep{zhou2025mogernn} 在同一个模型中考察了新增与失效的传感器，与本文最为接近，但它依据节点的输入特征选择图专家，没有把接入或失效的进程作为显式的输入。

因此，本文要回答的核心问题是：\emph{当各位置的本地读数随接入而增加、随失效而减少时，如何用同一组固定的参数，预测处于不同观测状态的所有位置？} 回答这一问题面临两个相互关联的挑战：\emph{（1）如何描述每个位置的观测状态，使模型能够区分“从未接入”“刚刚接入”与“已经失效”等不同情形；（2）如何依据观测状态，协调各位置自身的历史读数与来自关联位置的空间信息。}

针对这两个挑战，我们提出 ALFNet（Adaptive Lifecycle Forecasting Network）。对于第一个挑战，ALFNet 把 OS 表示为逐步的输入：观测角色标明节点在该步是在线（ON）、新接入（NEW）、无观测（UNO）还是已失效（OFF），观测掩码标明该步的读数是否可用，并辅以接入或失效已持续的比例（状态进度）。对于第二个挑战，ALFNet 让 OS 参与三个模块的计算。观测支持感知历史补全（SAHC）利用可见读数和路网关联，为全部节点补出一份完整的历史，供后续模块共用。空间上下文时间条件分支（ALFTemporal）把节点划分为空间分区，从其他节点的历史中提取条件特征，再经特征级线性调制（FiLM）作用于图预测分支，为本地读数不足的节点提供参考。观测条件化图预测（ALFGraph）配有五种图传播算子，编码的每一步都由 OS 决定它们的组合权重，使空间信息的交换方式随观测状态而变，最后解码得到预测。名称中的“自适应”指计算随输入的 OS 变化，模型参数在推理时保持不变。这些模块借鉴了图循环插补~\citep{cini2022filling}、空间分区交互~\citep{fang2025efficient}、两阶段注意力~\citep{zhang2023crossformer}、特征级线性调制~\citep{perez2018film}、图专家混合~\citep{zhou2025mogernn,wang2023graph} 与扩散卷积循环网络~\citep{li2018diffusion} 的做法。与 MoGERNN 相比，ALFNet 同样使用图专家混合，区别在于路由的依据与作用位置：ALFNet 的路由只由 OS 决定、不读取信号值，并作用于编码器每一步的图传播。

我们在 METR-LA、PEMS-BAY、PEMS04 与 PEMS08 四个数据集上，与四类共十一个方法在三个随机种子下做了统一比较。评价按目标位置在窗口内的观测轨迹分为四类场景：全程无读数（Unseen）、全程可读（Steady）、窗口内接入（Join）与窗口内失效（Fault）。ALFNet 四类场景平均误差（LifeAvg）的三项指标在四个数据集上均为最低，平均绝对误差（MAE）比最强的比较方法低5.59\%–14.95\%；在本地读数逐步增加或中断的 Join 与 Fault 场景下，三项指标在四个数据集上均为最低。

本文的贡献概括为三点：（1）问题与评价：提出动态观测支持下的归纳时空预测设置及其评价协议，按目标位置的观测轨迹划分四类场景，并按接入或失效后的持续步数划分阶段，用来检验预测能否随本地读数的增减而调整；（2）方法：提出 ALFNet，把 OS 表示为逐步的输入（观测角色、观测掩码及状态进度），并让它参与历史补全、跨节点条件特征的提取和图传播的路由；（3）实验：四个数据集、十一个比较方法、三个随机种子的统一比较表明，ALFNet 的 LifeAvg 三项指标均为最低，Join 与 Fault 场景的三项指标在四个数据集上也均为最低；五项消融表明，去除 OS 输入、SAHC、ALFTemporal 内部的跨节点交互、整个时间条件分支或 OS 路由中的任何一项，四个数据集上的 LifeAvg MAE 都会上升，各组件都对预测有贡献。
