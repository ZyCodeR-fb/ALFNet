\section{实验}\label{sec:exp}
实验回答四个问题。\textbf{RQ1}：在动态 OS 下，ALFNet 的预测误差是否低于已有方法，优势出现在哪些场景和阶段？\textbf{RQ2}：ALFNet 的各个组件分别起多大作用？\textbf{RQ3}：预测目标不变时，ALFNet 的预测如何随本地历史的加入、中断以及可见读数的时间位置而变化？\textbf{RQ4}：在单个样本上，预测行为是什么样的？实验使用 METR-LA、PEMS-BAY、PEMS04 和 PEMS08 四个数据集。与其他方法的比较（\ref{sec:4_2}、\ref{sec:4_3}节）在测试集上进行，并在三个随机种子上重复；组件消融（\ref{sec:4_4}节）在测试集上进行，使用一个种子；固定权重的配对机制分析（\ref{sec:4_5}、\ref{sec:4_6}、\ref{sec:4_8}节）与单因素超参数敏感性实验（\ref{sec:4_7}节）在四个数据集的验证集上进行，保留节点比例实验（\ref{sec:4_7}节）在 METR-LA 的测试集上进行，三者都使用一个种子。完整的分阶段结果、消融结果、保留节点比例结果、比较方法的实现以及配对干预与路由权重的补充分析见附录。

\subsection{实验设置}\label{sec:4_1}

\textbf{数据集与任务。} METR-LA 与 PEMS-BAY 来自~\citep{li2018diffusion}，PEMS04 与 PEMS08 来自~\citep{guo2019attention}。四个数据集均以5分钟为采样间隔，使用过去12步预测未来12步。METR-LA 与 PEMS-BAY 预测交通速度，PEMS04 与 PEMS08 预测交通流量；速度与流量在各自原始单位下评价，不跨数据集平均绝对误差。

时间按60\%／20\%／20\%顺序划分为训练、验证和测试时段。在拓扑已知的归纳设置下，训练仅使用已知节点的动态信号，验证与测试分别引入各自的保留节点；标准化统计量仅由训练时段的已知节点计算。与其他方法的比较在三个随机种子（32、42、52）上重复。随机种子同时决定节点划分（哪些节点是已知节点、哪些是验证或测试的保留节点）与模型初始化，因此不同种子之间的差异既包含训练的随机性，也包含节点划分的不同。表\ref{tab:main_speed}与表\ref{tab:main_flow}报告三个种子的均值与样本标准差；消融、机制分析与敏感性实验只使用种子32。

\textbf{场景与阶段协议。} Unseen、Steady、Join 与 Fault 四类场景（\ref{sec:3_1}节）等配额。评价时，Unseen 与 Join 在对应阶段的保留节点上构造，Steady 与 Fault 在已知节点上构造。为观察本地证据的积累与流失，再按事件持续步数 $m$ 划分阶段：Join 分为冷启动（Cold，$m=1$）、预热（Warm，$2\le m\le 11$）与就绪（Ready，$m=12$），Fault 按相同区间分为中断初期（Onset）、证据衰减（Decay）与完全中断（Outage）。Ready 与 Steady 的整个窗口都处于可读状态，Outage 与 Unseen 的窗口内都没有本地读数，它们的评价节点与 OS 输入各不相同：Ready 与 Unseen 在训练中没有动态信号的保留节点上评价，Steady 与 Outage 在已知节点上评价；四者的观测角色与状态进度输入也不同，Ready 为 NEW 且状态进度由 $1/12$ 增至1，Steady 为 ON 且状态进度恒为1，Outage 为 OFF 且状态进度由 $1/12$ 增至1，Unseen 为 UNO 且状态进度为0。自然缺失与协议共同决定最终掩码，因此阶段长度不总等于有效观测数。所有方法共享划分、预测目标、数据暴露边界与评价掩码。

\textbf{比较方法。} 比较方法共十一个，按其原本面向的研究方向归入第\ref{sec:related}节的四组，表\ref{tab:main_speed}与表\ref{tab:main_flow}按同样的分组排列。（1）未观测位置的归纳预测（\ref{sec:2_1}节）：MoGERNN~\citep{zhou2025mogernn} 与 SLPF~\citep{liu2025spatiotemporal}。（2）不完整观测下的预测（\ref{sec:2_2}节）：GinAR~\citep{yu2024ginar} 与 Merlin~\citep{yu2025merlin}。（3）传感网络变化与跨路网泛化（\ref{sec:2_3}节）：STONE~\citep{wang2024stone}、MCPST~\citep{fofanah2026pimcst} 与 STBP~\citep{liu2026general}。（4）时空预测主干（\ref{sec:2_4}节）：STGCN~\citep{yu2018spatio}、STID~\citep{shao2022spatial}、PatchSTG~\citep{fang2025efficient} 与 MetaDG~\citep{zou2026meta}。所有方法都在本文的协议下重新训练：使用相同的节点划分、输入信息、预测目标与评价掩码，推理时都不更新参数；各方法的实现见附录A.5。

\textbf{评价指标。} MAE、均方根误差（RMSE）与平均绝对百分比误差（MAPE）均在原速度（流量）尺度上计算，MAPE 以百分比表示，其分母为目标值的绝对值并以 $10^{-6}$ 为下限，因此流量数据的 MAPE 对低流量目标很敏感，部分基线的 MAPE 超过100\%。各场景内按日历与事件进展分层平衡汇总，再对四类场景等权平均得到 LifeAvg；LifeAvg RMSE 是场景级 RMSE 的平均。三项指标分别反映绝对误差、大残差和相对误差。

\textbf{训练与实现。} 四个数据集的 ALFNet 采用相同的网络结构，均含1,037,529个参数，训练目标见\ref{sec:3_5}节。模型使用 AdamW 优化器训练，批大小为64，最多训练100轮，第40轮起以耐心值10提前停止，并按验证集 LifeAvg MAE 保存权重。图预测分支的学习率为 $5\times10^{-4}$，其余模块使用较小的固定学习率，各数据集再统一乘以下表中的学习率倍率。数据集之间只在下表所列的设置上不同，这些设置在训练前确定：分区数与分区容量对应\ref{sec:3_3}节的 $P$ 与 $C$，窗口插值按\ref{sec:3_2}节所述执行，解码残差倍率与中心化强度分别对应式~\eqref{eq:11}中的 $d$ 与式~\eqref{eq:5}中的 $\alpha$。ALFTemporal 的 dropout 均为0.1。

\textbf{总体结果。} 在四类场景的平均（LifeAvg，附录表\ref{tab:app-lifeavg}）上，ALFNet 的三项指标在四个数据集上均为最低。相对各指标上最强的比较方法，MAE 在 METR-LA、PEMS-BAY、PEMS04 与 PEMS08 上分别降低12.25\%、13.54\%、14.95\%和5.59\%，RMSE 降低6.95\%–14.02\%，MAPE 降低12.85\%–18.77\%。按单个种子分别比较，ALFNet 的 LifeAvg 三项指标在三个种子、四个数据集上也都是最低，这一优势在不同的节点划分与初始化下保持一致。四个数据集的路网规模、预测变量与误差量级各不相同，ALFNet 以相同的网络结构在其上都取得了最低的综合误差，说明把 OS 作为输入并据此协调本地读数与空间信息的做法，对速度与流量预测都有效。

\textbf{分场景结果。} ALFNet 在四类场景上都有优势。四个数据集、四类场景、三项指标共48项结果中，ALFNet 有41项最低，其余7项为次低，即每一项都位列前两名。在本地读数随接入而增加、随失效而中断的 Join 与 Fault 场景下，ALFNet 的三项指标在四个数据集上全部最低：Join 的 MAE 比最强的比较方法低3.86\%–6.55\%，Fault 的 MAE 低4.57\%–15.02\%。这两类场景正是本文关注的观测变化，结果与引言的设想一致：用观测角色与状态进度描述接入和失效的进程之后，模型在读数增减时的预测更准确。在读数完整的 Steady 场景下，ALFNet 的 MAE 与 RMSE 在四个数据集上同样最低，MAE 低0.34\%–4.32\%，说明对观测变化的建模同时保持了常规条件下的精度。在全程没有本地读数的 Unseen 场景下，ALFNet 的三项指标在四个数据集上均位列前两名，在 METR-LA 上比最强的比较方法低4.00\%–8.97\%。

PEMS04 与 PEMS08 缺少传感器的 WGS-84 坐标，ALFTemporal 依据路网拓扑以广度优先搜索（BFS）分区；在具备坐标的两个速度数据集上，单独将 KD-tree 分区换为 BFS 后，种子32的 Unseen 测试 MAE 分别上升7.34\%和5.26\%，提示分区方式可能是流量数据上 Unseen 精度受限的因素之一（附录图\ref{fig:app-partition}）。

各场景上最强的比较方法并不相同。以 METR-LA 的 MAE 为例，Unseen 场景下是 MoGERNN，Steady 与 Fault 场景下是 STBP，Join 场景下是 MetaDG。ALFNet 用同一组参数在四类场景上都位列前两名，因此四类场景平均后的降幅（5.59\%–14.95\%）大于多数单个场景的降幅。

四个数据集、六个阶段、三项指标共72项结果中，ALFNet 有68项最低；六个阶段的 RMSE 在四个数据集上全部最低，METR-LA 与 PEMS08 的18项全部最低。ALFNet 在 Join 与 Fault 场景的各个阶段都有优势。

在 Join 的三个阶段，ALFNet 的 MAE 与 RMSE 在四个数据集上均为最低。MAE 的降幅在只有一步本地读数的 Cold 阶段为0.86\%–5.49\%，在读数逐步增多的 Warm 阶段为2.88\%–5.65\%，在整个窗口都有读数的 Ready 阶段为1.34\%–6.51\%。优势贯穿接入的全过程：读数刚出现时，ALFNet 能借助关联位置做出预测；读数增多后，它能把新增的读数用起来。

在 Fault 的 Onset 与 Decay 阶段，ALFNet 的三项指标在四个数据集上全部最低，MAE 降幅分别为4.59\%–7.29\%和4.40\%–11.38\%。在整个窗口都没有读数的 Outage 阶段，ALFNet 的 RMSE 在四个数据集上均为最低，降幅为2.29\%–18.08\%；METR-LA 与 PEMS08 上的 MAE 降幅达到16.75\%和17.86\%。从读数刚中断到完全中断，ALFNet 都保持了优势，说明它在本地读数流失后能够转而依靠空间信息。

\subsection{各组件的作用（RQ2）}\label{sec:4_4}

引言提出了两个挑战：如何描述观测状态，以及如何依据观测状态协调本地读数与空间信息。表\ref{tab:ablation}按这两个挑战安排了五项消融。针对第一个挑战，w/o OS 让模型中所有可学习的计算都不再接收观测角色、状态进度与掩码，掩码只用来在补全时保留观测值以及计算损失。针对第二个挑战的三个模块有四项：w/o SAHC 去掉图循环补全、窗口内插值与参考中心化；w/o Spatial Context 保留两阶段注意力的参数与 FiLM 调制，只把 ALFTemporal 内部的跨节点交互改为逐节点处理，SAHC 与 ALFGraph 使用的空间信息不变；w/o ALFTemporal–FiLM 去掉整个时间条件分支及其调制；w/o Adaptive Routing 保留五个图专家，但用与输入无关的全局可学习权重代替由 OS 决定的路由。所有变体与完整模型使用相同的超参数、随机种子（32）、节点划分与权重选择准则，训练目标不变。表\ref{tab:ablation}中各行均为种子32的结果，下文的百分比相对完整模型（ALFNet 一行）计算。四类场景与六个阶段上的完整消融结果见附录表\ref{tab:app-abl-scenario}与表\ref{tab:app-abl-phase}。

完整模型的 LifeAvg MAE 在四个数据集上均低于全部五个变体，三项指标共12列中有11列最低。去除任何一个组件，误差都会上升，各组件都对预测有贡献。

\textbf{OS 表示。} 去掉全部 OS 输入后，12列误差全部上升，MAE 在四个数据集上分别上升11.97\%、2.24\%、5.34\%和20.00\%。把观测角色、状态进度与掩码作为输入，使模型能够区分不同的观测状态，这对应引言的第一个挑战。

\textbf{历史补全。} 去掉 SAHC 后，四个数据集的 MAE 与 MAPE 全部上升：MAE 在 METR-LA 与 PEMS08 上分别上升5.94\%和7.80\%，PEMS08 的 MAPE 上升46.78\%。SAHC 为全部节点补出的共享历史，给后续两个模块提供了更好的输入。

\textbf{跨节点交互与时间条件分支。} w/o Spatial Context 只把 ALFTemporal 内部的跨节点交互改为逐节点处理，12列误差全部上升，MAE 上升1.84\%–15.23\%，在 METR-LA 与 PEMS08 上超过14\%。从其他节点的历史中提取的条件特征，为本地读数不足的节点提供了有效的参考。w/o ALFTemporal–FiLM 去掉整个时间条件分支，12列误差全部上升，MAE 上升6.13\%–11.22\%，说明时间条件分支对图预测分支的调制在四个数据集上都起作用。

\textbf{OS 路由。} w/o Adaptive Routing 使12列误差全部上升，MAE 上升0.66\%–5.45\%，PEMS08 的 MAPE 上升35.76\%。在图专家相同的情况下，由 OS 决定专家的组合优于与输入无关的固定组合。附录图\ref{fig:app-router}给出了训练后的路由权重：路由器为不同的观测角色学到了不同的专家组合，例如 NEW 角色下恒等专家的权重在 PEMS-BAY 与 METR-LA 上分别约为0.42和0.33，高于均匀组合的0.20。

五项消融共同表明，OS 表示与三个模块都降低了预测误差，分别回应了引言提出的两个挑战。

\subsection{观测轨迹下的预测响应（RQ3）}\label{sec:4_5}

条件平均无法区分交通目标变化和观测变化的影响。为隔离 OS 的变化，我们在四个数据集的验证集上做配对干预：取 Fault 场景中焦点节点的历史与未来读数都自然完整的全部窗口（METR-LA、PEMS-BAY、PEMS04 与 PEMS08 分别为1,585、2,600、843和887个；一个窗口有多个符合条件的节点时按固定随机规则取一个，不依据预测误差筛选），保持预测目标、图结构和其他节点的输入不变，只改变焦点节点的可用读数。加入干预只保留最近3步或6步读数，以完整的12步为参照；中断干预删除最近3步、6步或全部读数；两种干预都同步更新观测角色与状态进度。模型参数固定，因此结果反映模型对可用读数的响应，而不是在线学习的效果。

\ref{sec:4_5}、\ref{sec:4_6}与\ref{sec:4_8}节的对比模型取自四组比较方法：在每个数据集上，每组取验证集 LifeAvg MAE 最低的方法。MoGERNN（未观测位置的归纳预测）、Merlin（不完整观测下的预测）和 STBP（传感网络变化与跨路网泛化）在四个数据集上都入选；时空预测主干一组在 METR-LA 与 PEMS-BAY 上是 STGCN，在 PEMS04 与 PEMS08 上是 PatchSTG。各模型均使用种子32的最终权重，即表\ref{tab:main_speed}、表\ref{tab:main_flow}所用三个种子之一。图\ref{fig:trajectory}给出各模型在六个干预设置下的平均 MAE。

四个数据集各有六个干预设置，共24个；ALFNet 在其中21个上平均 MAE 最低。使用完整历史以及删除最近3步、6步读数时，ALFNet 在四个数据集上都最低；在 PEMS-BAY、PEMS04 与 PEMS08 上六个设置全部最低，比最强的代表方法分别低3.59\%–10.31\%、2.16\%–7.75\%和1.20\%–13.15\%。在同一批窗口上逐一比较（附录图\ref{fig:app-traj-diff}），四个代表方法在24个设置上共有96个与 ALFNet 的配对 MAE 之差，其中82个的95\%区间整体大于零（ALFNet 更低），没有一个整体小于零。

ALFNet 的预测随本地读数的增减而有序变化。加入干预下，只保留最近3步读数时，ALFNet 的 MAE 与使用完整历史时相比最多只高4.64\%（METR-LA，3.389对3.239），说明它能利用刚接入的少量读数。中断干预下，ALFNet 的 MAE 在四个数据集上都随删除步数单调上升，例如 METR-LA 上依次为3.239、3.556、3.693和4.227，上升平缓，没有出现突变。相比之下，在 PEMS04 与 PEMS08 上，Merlin 与 STBP 的误差在读数全部中断时急剧上升，达到 ALFNet 的1.83–2.45倍；ALFNet 此时的 MAE 为45.857和34.370，比最强的代表方法低7.75\%和13.15\%。这些结果与引言的设想一致：把接入与失效的进程作为输入之后，同一组参数既能在读数刚出现时尽快用上它们，也能在读数中断后转而依靠空间信息，使误差平稳变化。

\subsection{观测数量与时间布局（RQ3）}\label{sec:4_6}

引言指出，只统计有多少读数不足以描述预测所处的条件。为检验这一点，我们让焦点节点保留相同数量的读数（$q=3$、6或9步），但分布在12步历史的不同位置，共四种布局：Recent 保留最近的 $q$ 步，对应节点在窗口内接入；Early 保留最早的 $q$ 步，对应节点在窗口内失效；Middle Gap 保留两端、去掉中间连续的一段，Dispersed 等间隔保留 $q$ 步，二者对应在线传感器的通信丢包。按\ref{sec:3_1}节的定义，接入与失效同步更新观测角色与状态进度，通信丢包保持 ON 角色、只改变观测掩码。读数的布局在交通状态变化时才影响预测，因此本节在\ref{sec:4_5}节的配对窗口中取焦点节点历史读数波动较大的一半：12步历史读数的标准差不低于该数据集全部配对窗口的中位数（METR-LA、PEMS-BAY、PEMS04 与 PEMS08 分别为793、1,300、422和444个）。这一条件只依据输入的历史读数，与预测结果无关。其余输入、图结构与预测目标保持不变，所有设置只删除自然存在的读数。图\ref{fig:layout}给出五个模型在12个数量与布局设置下的 MAE。

ALFNet 在读数的数量和布局变化时都保持优势。四个数据集、四种布局、三种数量共48个设置中，ALFNet 在41个上平均 MAE 最低。保留9步读数时，四个数据集、四种布局的16个设置全部最低；四种布局各自的12个设置中，Recent、Early、Middle Gap 与 Dispersed 分别有11、10、11和9个最低。在 PEMS04 上12个设置全部最低，比最强的代表方法低2.36\%–7.50\%；在 PEMS-BAY 上12个设置中有11个最低，降幅为2.46\%–14.31\%。与设置最接近的 MoGERNN 相比，ALFNet 在全部48个设置上 MAE 都更低。在同一批窗口上逐一比较，四个代表方法在48个设置上共有192个与 ALFNet 的配对 MAE 之差，其中162个的95\%区间整体大于零。

读数数量相同时，误差随布局明显变化。以 $q=6$ 为例，ALFNet 在 Early 下的 MAE 比 Recent 下高13.6\%（METR-LA）、21.9\%（PEMS-BAY）、22.6\%（PEMS04）和25.9\%（PEMS08）。在四个数据集上，最近3步读数都比最早9步读数更有用：Recent 布局 $q=3$ 的 MAE 低于 Early 布局 $q=9$ 的 MAE（METR-LA 为4.625对4.968，PEMS08 为25.964对29.678）。可见，决定预测条件的是读数的新近程度与时间覆盖，读数的数量只是其中一个方面。ALFNet 用逐步的观测角色、状态进度与掩码描述读数出现在哪些步，因而在四种布局下都能给出更准确的预测，这为第一个挑战中“用逐步输入描述观测状态”的做法提供了依据。

\subsection{样本层面的预测行为（RQ4）}\label{sec:4_8}

完全中断时，ALFNet 的平均 MAE 在 PEMS-BAY、PEMS04 与 PEMS08 上是五个模型中最低的（2.563、45.857和34.370）。MoGERNN 是与本文设置最接近的方法，同样面向没有本地读数的位置。与它逐窗口比较，ALFNet 在四个数据集上都在多数窗口上误差更低：METR-LA、PEMS-BAY、PEMS04 与 PEMS08 上分别有60.9\%、67.9\%、57.3\%和64.9\%的窗口。平均每个窗口的 MAE 比 MoGERNN 低0.607、1.055、3.852和10.373，相当于 MoGERNN 平均 MAE 的12.6\%、29.2\%、7.7\%和23.2\%；四个差值的95\%配对自助区间都整体大于零。窗口 MAE 的中位数同样在四个数据集上都低于 MoGERNN（2.510对2.976、1.437对2.106、32.015对38.091、23.236对31.143），可见优势来自大多数窗口，而非少数窗口。

图\ref{fig:cases}(a)中，ALFNet 的误差分布在 PEMS04 与 PEMS08 上整体位于其他模型的左侧，第10、25、50与75百分位都是五个模型中最低的；Merlin 与 STBP 在读数全部中断后误差大幅上升，在这两个数据集上的平均 MAE 达到 ALFNet 的1.83–2.45倍。图\ref{fig:cases}(b)的示例中，焦点节点的历史全部被删除，各模型只能依靠其他节点。ALFNet 的预测最接近真值；在 PEMS04 的示例上，Merlin、STBP 与 PatchSTG 的预测明显高于真值，MAE 为130.978、203.705和95.933，ALFNet 为7.963。这与\ref{sec:4_4}节的消融一致：ALFTemporal 从其他节点的历史中提取条件特征，为本地读数不可用的节点提供了参考。
