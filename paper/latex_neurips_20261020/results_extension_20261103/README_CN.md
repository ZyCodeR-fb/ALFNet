## 4. 解读要点与边界

- **STOP 是需要作者决定的主要事项。** STOP 在 PEMS-BAY、PEMS04、PEMS08 的测试 LifeAvg 均优于 ALFNet（PEMS08 MAE 22.70 对 36.78），METR-LA 上 ALFNet 仍更好。STOP 的优势几乎全部来自 Unseen（测试 MAE：PEMS04 39.84 对 78.07，PEMS08 30.64 对 85.42，PEMS-BAY 3.49 对 4.54，METR-LA 4.74 对 4.85）；Join 略优；已知节点的 Steady/Fault 两者接近，速度数据集上 ALFNet 的 Fault 更好（METR-LA 3.73 对 4.50）。这也说明 ALFNet 在流量数据集 Unseen 上的弱点是 LifeAvg 差距的主要来源。其 Core_Adaptive 在全部节点上做集中式汇聚，使无历史节点能借用全网当前状态。已用 STOP 的 PEMS08、METR-LA 最终权重在真实验证样本上做反事实检查：替换全部未来目标、替换全部不可见输入后，输出逐元素不变，即没有读取未来或被遮蔽的数据。
- 加入 STOP 后，"至少 80% 第一"在三个数据集不成立；只在不含 STOP 的比较集合中成立（HD-TTS 时 PEMS04 为 26/33，差一格）。
- Merlin、STONE 在本协议下全面弱于 ALFNet；STONE 明显弱于其他所有方法（PEMS04/08 MAPE 92.6/110.2），可能与其源设置（新节点有历史、按年份分布外）和本协议差异较大有关，结果按冻结流程如实保留。
- 两项整体消融在四个数据集三项 LifeAvg 上几乎全部变差，唯一例外是 PEMS04 w/o SAHC 的 RMSE（−0.85%）；PEMS08 w/o OS 只有 24/33 格变差，但 LifeAvg 三项均变差 20% 以上。
- 单次运行（seed 32）；比较方法均为共同协议下的适配版本，适配差异见 `docs/comparison_model_audit.md` 2026-11-03 节。
