# BFS 分区与 OS 表示消融（2026-11-20 复算）

种子 32。11 月 16 日补充计划的 10 次训练均已完成。以下使用各自最佳检查点的已保存验证指标，新训练的 10 张表已逐一与运行目录中的 `development_validation_table.json` 对照。当前没有该补充计划的测试结果。正文表 3 采用测试集，本页单独记录验证结果。

## 分区对 Unseen 的影响

只在具备经纬度的两个速度数据集上比较。两组从相同参数初始化，保留坐标特征和各自原分区容量，替换分区成员后分别训练。相对变化以 KD-tree 为分母，正数表示误差上升。MAPE 列为百分数。

| 数据集 | 分区 | MAE | RMSE | MAPE |
|---|---|---:|---:|---:|
| METR-LA | KD-tree | 6.574 | 9.185 | 19.174 |
| | BFS | 7.659 | 10.839 | 20.816 |
| | 相对变化 | +16.49% | +18.01% | +8.56% |
| PEMS-BAY | KD-tree | 5.160 | 7.405 | 13.842 |
| | BFS | 5.054 | 7.347 | 13.416 |
| | 相对变化 | −2.05% | −0.77% | −3.08% |

两个数据集的变化方向相反。PEMS04 和 PEMS08 原本使用 BFS，本轮没有它们的 KD-tree 配对结果，因此无法由这次对照确定流量数据集 Unseen 表现的原因。

## OS 表示消融的 LifeAvg 第一优格数

每个单元依次列 MAE / RMSE / MAPE，越小越好。按未舍入值逐列比较，四个数据集共 12 格，均无并列。最后一列比较 Full 和四个 OS 变体。

| 配置 | METR-LA | PEMS-BAY | PEMS04 | PEMS08 | 第一优 |
|---|---|---|---|---|---:|
| Full | **4.527 / 6.885** / 13.642 | 2.956 / 4.605 / **7.603** | 40.021 / 54.339 / **31.915** | **32.602 / 42.974 / 29.495** | 7 |
| w/o Observation Role | 4.614 / 6.950 / 13.720 | **2.916 / 4.541** / 7.650 | **39.119 / 52.525** / 33.226 | 34.416 / 45.317 / 34.279 | 4 |
| w/o Observation Mask | 4.670 / 6.959 / **13.602** | 2.945 / 4.656 / 7.891 | 39.685 / 52.940 / 34.752 | 35.146 / 46.149 / 32.375 | 1 |
| w/o State Progress | 4.605 / 6.939 / 13.819 | 2.964 / 4.679 / 7.828 | 39.151 / 52.908 / 34.404 | 35.432 / 46.756 / 31.609 | 0 |
| w/o OS | 4.796 / 7.028 / 14.461 | 3.008 / 4.680 / 7.877 | 41.968 / 56.634 / 35.798 | 38.166 / 49.765 / 31.291 | 0 |

单独与 Full 配对，去掉全部 OS 后误差在 12/12 格上升，去掉状态进度为 10/12，去掉角色为 8/12，去掉掩码也为 8/12。去掉角色还会把输出细化的角色倍率改为常数，去掉掩码只屏蔽可学习路径中的显式掩码，真实掩码仍用于保留观测值等操作。单种子结果支持完整 OS 相对整体移除的收益，对单项输入的收益则应限定数据集和指标。

若按扩展后的整张表 3 比较，加入 w/o SAHC、w/o Spatial Context、w/o ALFTemporal–FiLM、w/o Adaptive Routing，只有 PEMS04 的 MAE 和 RMSE 换了第一名，均由 w/o SAHC 取得（38.362、51.563）。此时 Full 7 格、w/o Observation Role 2 格、w/o SAHC 2 格、w/o Observation Mask 1 格，其余均为 0。
