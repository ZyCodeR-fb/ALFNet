# 重跑结论

两项训练及test均完整结束；两个checkpoint完整33格validation复核最大绝对差均为0。测试使用原seed32、原配置和按validation选定的best权重，未更改评价定义。198项test数值保存在test_cells.csv（两数据集×Full/原消融/重跑×33）。

## 是否满足三项LifeAvg均高于Full

- PEMS04 w/o State Age：重跑test为39.756516 / 53.136207 / 24.957346，相对Full为+0.48% / -0.39% / +7.31%。只有RMSE仍较好，因此不满足。相比原消融，本次三指标分别上升1.13% / 1.34% / 4.19%；“比原消融差”与“全部比Full差”是两个不同判定。
- PEMS08 w/o Adaptive Routing：重跑test为37.303480 / 47.299133 / 45.890848，相对Full为-3.73% / -3.42% / +5.94%。MAE/RMSE仍较好，因此不满足。相比原消融，MAE/RMSE又下降1.49% / 1.79%，MAPE上升0.63%；重跑并没有一致地变差。

完整33格中，本次消融比Full差的数量分别为29/33和19/33。该计数包含相互关联的主条件、阶段及LifeAvg，不是独立显著性检验。原论文表格和历史消融结果没有替换。

## 解释与建议

PEMS04年龄特征对MAE的结论随同seed重复而变化，不能只用一遍的符号判断稳定收益；MAPE在两次test中均受益于完整模型。PEMS08静态混合在两次test中均改善MAE/RMSE、恶化MAPE，当前证据更支持指标间取舍，而非单次意外。

同seed配置复现仍出现数值差异；已核验数据/配置/实际训练代码一致及预检保留参数初始化一致，但尚未定位具体非确定性算子，不能将差异直接归因于某一CUDA核或并发。PEMS04最佳epoch从65变为36，PEMS08两次都是50，不同轨迹/权重可有相同最佳epoch。

建议到此停止重跑，保留两次完整结果，不按误差方向挑选一遍替换另一遍。明确区分跨数据集一致的Spatial Context、ALFTemporal–FiLM贡献与Age/Routing的条件依赖贡献；本轮不支持“所有重要组件都在四数据集上全面提升三项LifeAvg”。
