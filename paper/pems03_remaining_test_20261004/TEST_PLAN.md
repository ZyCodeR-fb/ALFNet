# 其余五候选test与分布诊断

用户明确授权：检查validation/test差异原因，尝试其他候选test；简单问题可修复，复杂则停止PEMS03，正文维持四数据集。

固定本轮另外五个已训练checkpoint：中心0/LR1、中心0/LR2、中心.5/LR2、中心1/LR1、中心1/LR2。中心.5/LR1已有test复用，原版/旧重建也复用。禁止在本轮根据中途test增添配置或更换epoch。每个新候选先恢复对应support/unified适配器并校验方法契约，完整复核33格validation后才test，最多3个评估并发，无训练。

诊断授权包括读取PEMS03固定K/V/T节点在train/validation/test各时间段的分布，区分同节点时间变化与同时间节点组差异。统计仅用于事后解释，不拟合模型/归一化器，不改变划分/掩码/指标，不把test节点历史作为预测输入。复核评估权重、归一化、teacher-forcing禁用和样本计数。比较胜格变化与实际误差变化，避免把离散排名变化全解释为模型崩溃。

判定报告33格及LifeAvg三项，目标仍27格及三项平均指标领先八基线；test反馈评估属于探索性，完整保留失败结果。若无实现bug且无现有配置达标，停止本轮，不自动启动新的训练，正文维持METR-LA/PEMS-BAY/PEMS04/PEMS08。
