# External TPB Pattern Weights

Place the TPB pattern-center tensor here when running TPB-based RoleFusion configs on a server without the full `references` directory.

Required default file:

```text
external_weights/tpb_patterns/cosine_10_cl.pt
```

This file can be copied from:

```text
references/TPB/pattern/chengdu_metr_pems/cosine_10_cl.pt
```
