# Active experiment contract

This repository has one active experiment: the frozen `unified_BASE` ALFNet
and twelve comparison models under the same v4 data/evaluation protocol. Old
v3 and LF/SUP candidate code is not an active path. Historical outputs and
`configs/paper/archive/` remain immutable evidence.

## Data and protocol

| dataset | N | target/channel | unit | static layout | spatial patch capacity |
|---|---:|---|---|---|---:|
| PEMS03 | 358 | flow q/0 | veh/5min | component-aware graph BFS | 12 |
| PEMS04 | 307 | flow q/0 | veh/5min | component-aware graph BFS | 10 |
| PEMS08 | 170 | flow q/0 | veh/5min | component-aware graph BFS | 6 |
| METR-LA | 207 | speed v/2 | mph | KD-tree on verified WGS84 | 7 |
| PEMS-BAY | 325 | speed v/2 | mph | KD-tree on verified WGS84 | 11 |

Channel is an array index, not a variable count. Flow and speed are different
tasks; never pool their MAE/RMSE. Runtime data is exactly
`data_v4/<dataset>/{raw_data.pkl,unknown_nodes.npy}`. Preserve every
`data/<dataset>/original/`, `data_v4/`, manifest and `references/` file.

- split 60/20/20; input/horizon 12/12; stride 1;
- topology-known, signal-inductive full-N protocol;
- dynamic signal scope train K, validation K∪V, test K∪T;
- scaler fits training time and K only;
- zero-history/steady/join/fault sampled equally;
- seeds 32/42/52 control node split and named RNG streams; validation design
  seed is fixed at 12026;
- teacher forcing is sample-level, availability-masked, training-only;
- checkpoint selection is validation LifeAvg MAE, strict `<`, earlier tie;
- WorstGroup is not recomputed. The primary table is 33 cells: five main rows
  plus six phase rows, each with MAE/RMSE/MAPE.

## Models and fairness

Order in the plan is ALFNet, MoGERNN, HA, FC-LSTM, STGCN, STGODE, GWNET,
STID, ST-FiT, SLPF, PatchSTG, STBP and MCPST-FSL. All receive the same
full-N masked traffic tensor, time features (when used by the published
architecture), graph, origins, masks, checkpoint policy and metric arithmetic.
The generated YAML records each published method's optimisation loss (MAE for
methods whose source uses masked MAE; MSE for ALFNet, MoGERNN and MCPST-FSL).
Only ALFNet receives its method-specific lifecycle role/age/mask
features.

ALFNet is the pre-LF/pre-SUP `unified_BASE`: shared GRIN imputation, ALFGraph,
ALFTemporal, FiLM fusion and role-balanced forecast objective. ALFGraph keeps
the five historical labels `identity, mean, weighted_mean,
forward_diffusion, backward_diffusion`. Weighted mean equals forward diffusion;
on symmetric graphs forward also equals backward. This known redundancy and
low-flow MAPE instability are disclosed limitations, not silently repaired in
the selected BASE model.

Comparison wrappers preserve the referenced source architecture and replace
only interfaces that violate the common inductive contract (private data
loading, node-ID parameters, target formatting, or batch axes). See
`docs/comparison_model_audit.md` for the per-model source and adaptation.

## Configuration and plan authorities

All YAMLs are generated by `scripts/build_final_configs.py` under
`configs/<model>/<dataset>.yaml`. The sole active plan is
`configs/paper/final_plan.json`: 13 models × 5 datasets × 3 seeds = 195 slots.
Runtime code validates the YAML, plan, data and code hashes; it does not repair
them. Any architecture/loss/protocol change requires regenerating the plan and
retraining affected runs.

```bash
python scripts/build_final_configs.py --check
python scripts/build_final_plan.py --check
bash scripts/run_experiments.sh --dry-run

# all runs, up to five concurrent jobs (one 96GB GPU deliberately shared)
ALLOW_GPU_SHARING=1 JOBS=5 DEVICES=0,0,0,0,0 \
  bash scripts/run_experiments.sh

# arbitrary registered subsets
bash scripts/run_experiments.sh --model ALFNet --dataset PEMS08 --seed 32
bash scripts/run_experiments.sh --model STGCN --seed 32 --seed 42 --seed 52
bash scripts/run_experiments.sh --status --model MoGERNN
```

Validation/test audit, evaluation and collection stay plan-driven. Test is
opened only after the selected runs are complete and their validation
re-evaluation agrees with training-time values.
